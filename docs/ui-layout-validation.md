# UI 布局重构验证

日期：2026-10-08

## 范围

调整 App 默认导航、SwiftUI 页面布局和全局连接／任务展示。Python 后端、K2Core、BackendClient 及四个 Store 均未修改。原 DeviceCard 和 ProgressCard 由全局 ConnectionSidebar 与 TaskStatusBar 替代。

连接栏位于业务页面选择分支之外，收起仅改变显示宽度，不销毁组件。导航变化没有连接、断开、探测或刷新回调；启动时保留原来的一次设备刷新。连接用途只影响操作控件展示。

文件快捷键、拖放、裁剪 Sheet、升级／资源写入／恢复确认、E-Mark 删除确认和窗口关闭保护沿用现有实现。资源写入仍按布局、背景、开机图及 E-Mark 分别调用原接口，没有增加合并写入。

## 自动验证

- Python：70 项现有回归通过。
- Swift：31 项回归通过，包括新增的 3 项连接展示测试：等待数据与实时状态区分、过期／断开状态优先级、DFU 声明与读取确认区分。
- Universal 2 release 构建和本地签名通过；主程序 arm64 与 x86_64 的最低系统版本均为 macOS 13.0。
- 搬移后的应用验证通过：49 个 Mach-O 文件包含双架构；两种架构的冻结后台均通过 HID／SQLite 加载、曲线格式往返及固件／全部资源的模拟读写与恢复。
- `git diff --check` 通过。

## 布局检查

由于原生应用自动化工具持续报 `Sky Computer Use native pipe closed before response`，未完成实际窗口的点击验证。采用临时 NSHostingView 离线渲染，检查连接栏、上位机、固件升级、表盘、开机图、含配置的 E-Mark 和工程工具栏。

工作区使用 644 点窄宽度，并对表盘使用 824 点宽度检查。根据渲染结果调整表盘与 E-Mark 为编辑／属性并排，以及开机图预览／操作并排；设备操作固定在编辑滚动区之外。临时渲染代码未作为应用功能或常规测试提交，截图位于本地忽略目录 `build/ui-previews/`。

离线渲染不等同于真实窗口交互：SceneStorage 使用默认值，原生列表等控件的绘制也存在限制，不能据此声称已验证侧栏跨重启保存、菜单点击、拖拽或真实采集期间的页面切换。
