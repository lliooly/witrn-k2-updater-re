# K2 曲线工具实施计划

依据已批准的 [设计](k2-monitor-design.md)，在 main 分功能提交并推送。

1. 独立遥测解析与 MIT 许可：只读 HID 接收、浮点和长度校验、真实时间与方向保留；用独立二进制包验证。
2. SQLite 记录与文件交换：批量提交、分段与恢复、流式导入导出、官方字段兼容；验证错误行、跨天和缺失可选列。
3. 查询与统计：有界峰谷抽稀、区间插值、跨零积分、缺口规则；用解析可求解波形和百万样本验证。
4. 后台及原生页面：长期任务控制、Swift Charts、历史操作、设备互斥、自动停止、关闭保存；验证状态机和真实窗口。
5. 回归与打包：Python/Swift 回归、Universal2、应用签名和许可资源、真实采集（设备可用时）；明确未完成的硬件验证。

每阶段检查 diff、验证相关行为后提交，不提交官方程序、设备数据或第三方完整源码。
