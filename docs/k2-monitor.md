# 曲线与记录使用说明

0.5.0 将 K2 上位机曲线整合进现有 SwiftUI 应用。支持 macOS 13 起的 Apple Silicon / Intel；不需要另外安装 Python、SQLite 服务或浏览器。

## 开始采集与保存

1. K2 正常开机，用数据线从 CC1/HID 口连接 Mac。不按减号进入 DFU。
2. 打开「曲线与记录」，刷新、选择设备并连接。窗口先显示实时读数，曲线最多每两秒查询更新一次；读数最多每秒更新十次。
3. 选择电脑端采样上限，点击「开始记录」指定新的 `.sqlite` 文件。已有记录不会覆盖。
4. 暂停只暂停正式记录，预览继续；继续后开启新分段。停止会保存记录，连接可继续预览。断开或退出也会先提交并关闭设备接口。

采集只有 HID 读取，不发送 DFU、擦写、重置或远程采样设置。采集期间禁止固件、表盘资源与 E-Mark 的设备操作；本地编辑可继续。断连后不自动连接别的设备。五秒未收到有效遥测时停止并提示检查连接。

1、10、100 样本/秒及「全部接收」是电脑记录上限，不改变 K2 发送频率；窗口显示实际平均接收速率，不补造缺失样本。自动停止可按绝对电流或非负功率连续低于阈值触发，默认关闭；暂停、断连和长间隔重置触发计时。

## 曲线与统计

电压、电流、功率默认显示在共用时间轴的独立面板，温度和 D±可勾选。悬停查看附近样本，拖选区间或输入起止秒数计算统计，使用缩放、左右移动、全程概览及跟随最新调整范围。

图形由峰谷抽稀的有界样本绘制；统计使用原始记录，与图形点数无关。有效覆盖时长排除暂停、断连、重启与长间隔；起止边界在有效相邻样本之间线性插值，缺口不补齐。各测量提供最小、最大和时间加权平均。

电流保留设备符号；电量、能量分别显示正向、反向、净值和绝对累计。过零处拆分积分。绝对功率平均由有符号功率分段积分推导，容量 mAh 和能量 mWh 对应电脑记录期间的有效测量。设备自带 Ah/Wh 另行显示，不能把设备累计量当作本次电脑记录积分。

## 历史、导入和导出

「打开 / 导入」将官方 CSV、官方 SQLite 或本地 SQLite 读入新本地副本，保留源文件。默认记录列表支持直接查看及识别未正常结束的记录。导出支持全部或当前选区：

| 格式 | 保存内容 |
| --- | --- |
| 官方兼容 CSV | 官方元信息、跨天时间、电压、有符号电流、非负功率、外部温度、D±；UTF-8 BOM |
| 官方兼容 SQLite | `metadata`、`records`，官方字段和文本数值 |
| 完整本地 SQLite | 原始记录、分段、内部/外部温度、设备累计量、采样设置和结束标志 |
| PNG | 当前曲线范围及勾选的测量面板 |

官方格式没有本地分段和扩展字段，导出前会提示。缺失可选列显示为缺失；不填零。时间倒退、非有限值、列结构错误和错误时间会阻止导入并给出位置。无分段的官方文件按采样信息或有限前缀的时间差估计缺口，无法恢复文件中没有记录的暂停信息。

默认正式记录位于 `~/Library/Application Support/K2 Updater/Recordings/`，也可另选目录。预览使用临时、有界 SQLite：最多保留最近 30 分钟和 180000 个样本，正常断开后清理。开始正式记录后不会因展示窗口滚动删除正式记录。

正式记录每秒或每 100 个样本提交一次，先达到的条件生效；正常停止会提交剩余数据。崩溃后已提交数据仍可打开，未提交的最多一秒数据不保证恢复。写入失败停止记录并保留已提交内容。不要只复制运行中 SQLite 主文件作为备份，应使用应用的完整本地导出。

## 验证边界与复现

2026-10-08 验证结果：

- 68 项 Python 与 28 项 Swift 检查通过，覆盖解析、方向、采样、暂停、自动停止、设备互斥、文件交换、跨天、取消、积分和有界查询。
- 加速写入 1000000 个样本，数量正确、峰值保留；进程峰值内存增加 9715712 字节（约 9.3 MiB），写入与查询约 79.7 秒。此结果不是一天连续采集验证。
- 固定 100 Hz 模拟源运行 60 秒，接收 6000、保存 6000，文件正常结束；假传输的 write 方法会报错，验证流程未调用它。这不是 USB 实机验证。
- 49 个 Mach-O 均包含 arm64/x86_64；移动后的冻结后台在两种架构下完成 HID/SQLite 加载、曲线查询、CSV/官方 SQLite/本地 SQLite 交换，并完成既有固件和五类资源的模拟回归。
- 本机原生窗口可启动，新侧栏入口存在。允许窗口验收后，自动化连接出现 `Sky Computer Use native pipe closed before response`，重置后仍失败；完整页面操作、PNG 渲染和关闭交互未完成实窗验收。
- 用户选择暂不连接 K2，正常模式实机遥测、遥测校验字节行为、Mac 与设备读数对照没有验证；官方真实导出文件与 Windows 回读也没有验证。Intel 实机和 macOS 13 实机未运行。

协议来源与静态依据见 [调查](k2-monitor-research.md)。复现软件验证：

```sh
.venv/bin/python -m unittest discover -s tests
.venv/bin/python script/validate_monitor.py
.venv-app/bin/python script/validate_app.py 'dist/K2 Updater 0.5.0.app'
```

规模验证使用临时合成数据，不打开 USB。厂商二进制、采集文件、个人配置及逆向输出不进入 Git；应用包内保留协议改编的 MIT 许可证和来源。
