# K2 曲线采集实机验证

日期：2026-10-08。设备为用户的 K2，固件 5.8，正常模式，从 CC1/HID 口连接 Apple Silicon Mac。测试使用 0.5.0／0.5.1 应用包内的冻结后台，控制消息只影响电脑文件；采集流程仅调用 HID 读取和关闭，没有 DFU、擦写、USB reset 或远程设置。

原始报告、设备标识及 SQLite 记录仅保存在被 Git 忽略的 `k2_recordings/`；本文只记录方法和汇总，不包含设备序列号或 USB 路径。

## 采样修正与新版应用包复测

旧采样器以每次实际到达时间向后推一个采样周期。100 Hz 报告若在 9.999 ms 到达，就错过新的 10 ms 截止点并跳过一个包；这种反复推迟降低了保存率。

0.5.1 改为固定经过时间区间，每个区间最多选择一个已收到的真实样本，缺失区间不补造数据。新增 1000 个抖动到达和同区间突发的回归检查；另依据实机捕获启用报告双校验，并增加载荷及两个校验字节损坏时的拒绝检查。

- 修正后源码后台实机采集 15 秒，收到并保存 1501 个样本，约 100.000 样本/秒。
- **0.5.1 build 7 的冻结后台**连续记录约一分钟，保存 **6015** 个样本，首尾跨度 **60.138753 秒**，实际 **100.002074 样本/秒**。速率计算为 `(样本数 - 1) / 首尾跨度`。
- 最后状态中的 6015 个有效报告全部双校验匹配，坏报告计数为 0。停止后文件正常结束，正式样本数与控制确认数一致。
- 这份新版实机记录也完成三种格式导出／重新导入，均保留 6015 个样本；有界曲线查询返回 528 个绘图点，原始记录保持完整。

## 读数对照与验证边界

用户初次报告屏幕为 0.0001 V、0 A、0 W。无负载一分钟记录的电压约 0～0.002500 V，电流约 −0.003116～0.001798 A；最后一包为 0.001250 V、0 A、0 W、内部温度 25°C。此处只核对接近零的读数与字段含义，没有据此确认测量精度或有负载时的正反方向。

随后用户接入正常充电负载，报告屏幕为 **14.8 V、0.97 A、14.0 W**。使用同一 0.5.1 冻结后台采集约 30 秒，保存 **3015** 个样本，首尾跨度 **30.139992 秒**，约 **100.000026 样本/秒**；最后状态的 3015 个报告均校验匹配，坏报告为 0，正常关闭并完成三种格式往返。
