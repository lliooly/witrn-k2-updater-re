# K2Picture 实现步骤

设计已获用户批准。直接在当前工作区实现，不创建 worktree，不切换分支。

1. 核对 `.pic` 字段、字号映射、RGB565 结构和三类资源扇区，记录静态证据。
2. 实现 Swift 核心文件模型与编解码，以及 Python 资源备份、写入、恢复。资源地址固定，不接受任意地址。
3. 扩展现有 NDJSON 后台请求和共享任务状态，保持固件升级流程兼容。
4. 实现表盘画布、元素属性编辑、图片处理、工程保存和资源操作界面；保留开发测试在 UI 外。
5. 验证二进制往返、图片方向、资源边界、邻接数据、异常停止和恢复；运行现有固件测试。
6. 构建 Universal2 应用，验证 GUI、两种架构和重新打包。首次实机写入须在展示备份及具体目标后获得用户确认。
