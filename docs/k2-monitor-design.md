# K2 原生曲线与记录设计

2026-10-08。用户已选择完整曲线工具：实时读数、曲线、长时间记录、CSV/SQLite 导入导出、区间统计。本文为实施前审查稿；批准后按功能分批实现和推送。

## 实施方式

推荐复用 `didim99/witrn-driver` 的 MIT 协议定义，使用现有 HIDAPI 传输，新增 SwiftUI/Swift Charts 页面与 Python 记录后台。保留上游版权、MIT 许可、版本与修改说明；不引入 Bokeh 服务，不升级现有 Python 3.9 运行时。协议和官方文件的证据见 [调查说明](k2-monitor-research.md)。

替代方案：直接运行开源 Bokeh 工具能更快获得简单曲线，但仍缺完整历史回放与官方格式兼容；完全逆向重写控制更多，但会重复已经公开且可合法复用的协议工作。推荐方案兼顾原生体验和协议复用。

保持 macOS 13 起、Apple Silicon/Intel 双架构、自用 ad-hoc 签名。继续在当前 `main` 工作，不创建 worktree。此次只连接一台 K2；PD 解码、其他型号、远程控制、设备离线记录下载不纳入本次范围。

## 页面与操作

侧栏新增“曲线与记录”，与固件、表盘、虚拟 E-Mark 并列。

- 顶部为普通模式设备选择、连接状态、连接/断开、开始/暂停/继续/停止记录、记录文件位置和采样设置。
- 实时卡片显示电压、有符号电流、功率、内部/外部温度、D±、设备累计 Ah/Wh、记录时间、开机时间和记录组。没有有效数据时显示缺失状态与原因。
- 电压、电流、功率为默认曲线，温度和 D±可选择显示。不同单位采用独立纵轴面板，共用时间轴；支持悬停读数、缩放、移动、跟随最新和全程概览。
- 支持拖选时间区间，也可输入起止时间；下方显示该区间的统计及占全记录的比例。全程概览保留峰谷，选择区间后查询原始数据。
- 文件菜单支持打开记录、导入 CSV/SQLite、导出全部或选区，以及当前曲线 PNG。文件格式错误给出行号或字段，不静默跳过错误数据。

连接用于实时预览；开始记录后才保存正式记录。暂停记录时预览继续，暂停段不写测量样本；继续后开启新段。停止记录完成落盘，连接可继续预览。清除预览仅清除临时数据，不删除已保存记录。打开历史文件先停止当前预览；若正在记录，先让用户选择停止并打开或取消。

## 连接、采样与互斥

曲线使用 K2 正常运行模式，从 HID 口接入，不按减号进入 DFU。采集只打开所选 HID 接口并被动读取，禁止发擦写、DFU 握手或 USB reset。未收到遥测时说明检查连接和正常模式；不能只凭 VID/PID 判定设备运行模式。

共享设备操作协调器负责互斥：采集占用接口期间，设备上的固件/表盘/E-Mark 操作不可启动，提示先断开采集；本地文件编辑仍可使用。已有设备页面的 DFU 指引仅用于需要 DFU 的操作。

记录采样提供 1、10、100 样本/秒及“全部接收”。这些是电脑端记录上限，不声称改变 K2 发送速率。按单调时钟挑选实际收到的样本，不生成或复制测量值补齐频率。界面显示实际接收和记录频率；无法达到选择速率时保留真实时间戳。

HID 每包先检查报告长度、已确认的头部、命令、有效载荷长度及数值有限性；忽略非遥测帧并计数，不把错误包变成零值。遥测校验规则先经只读实机核对；不将尚未确认的 DFU 校验要求直接套用。断连、设备重启、睡眠或异常时间间隔形成新分段，读数标为过期，需用户重新连接后继续记录，不自动切换其他设备。

## 后台边界与数据流

- Python 遥测模块：小端解析、报告归一化、数值检查、主机单调时间戳；保留原始电流方向，功率同时保存 `V×I` 与 `V×abs(I)`。
- Python 记录模块：采样选择、SQLite 持久化、导入导出、历史查询和统计。使用标准库，不增加本地数据库服务。
- 后台桥接：新增长期采集任务及批量事件，UI 最多每秒刷新 10 次；终止任务先完成提交并关闭文件。后台收到 SIGINT 后有界退出，进程退出与末批事件均确认后释放设备占用。
- Swift `K2Core`：可测试的样本、状态和查询结果模型。`MonitorStore` 持有连接/记录/文件/选区状态，服务对象管理后台生命周期。
- SwiftUI 页面：只消费有界图形数据及统计结果，不持有完整历史样本。单次返回每条曲线最多 6000 个展示点，用每桶首尾和极值抽稀，时间与分段保持有序；统计始终读取原始记录。

预览使用后台有界缓冲，默认保存最近 30 分钟并按展示预算抽稀。正式记录的所有选定样本持续写入 SQLite；历史查询、文件导入导出和数据库提交不阻塞主线程。长任务可取消；已有文件不会因取消被覆盖。

## 记录文件与恢复

默认记录目录为用户 Application Support 下本应用的 `Recordings`；可在开始前选择其他目录。每次记录生成独立 SQLite 文件，含版本、创建日期、设备型号、采样设置、结束状态，以及数值列、时间戳、分段、设备累计量。设备路径和序列号不进入共享导出文件。

SQLite 使用 WAL；每秒或每 100 个样本提交一次，以先达到的条件为准。停止、暂停、自动停止和正常退出均提交；窗口关闭和退出应用若有记录，先确认是否停止保存。崩溃后保留已提交数据，下次打开可查看或导出未正常结束的记录；不宣称能恢复崩溃前尚未提交的最多一秒数据。

磁盘不足、写入错误或后台失败时停止记录并报告最后已提交位置，保留数据库；不继续显示记录成功。SQLite/WAL 文件不得仅复制主文件作为完整备份，导出使用 SQLite backup 或结束后的 checkpoint。导入生成新本地记录，原文件只读，失败/取消清理新建临时文件。

## CSV/SQLite 兼容

提供两类导出：官方兼容 CSV/SQLite，以及完整本地 SQLite。官方兼容格式使用调查说明中的元信息、时间文本和列名，功率保持官方非负约定；温度字段明确使用外部温度。完整本地文件保留内部温度、设备累计量、有符号功率及分段。

导入识别 UTF-8 BOM、普通 CSV 与官方元信息 CSV、可选列、行末空列、Excel 风格时间包装、一天以上时间、本地版本与官方 SQLite schema。元信息缺少时可显示未知日期/速率，但时间、电压、电流必需且有效；功率缺少时计算并标注来源。官方自带功率原样保留，同时派生有符号功率。

时间统一为记录经过秒数，日期信息单独保存。负时间、倒退时间、非有限数值和非法表结构拒绝导入并定位原因。重复时间允许显示和保存，但不积分零时长。可选列缺失显示为空，不填零。SQLite 只按固定支持的表/列查询，不执行输入文件中的任意 SQL，禁用扩展加载。

无分段信息的官方文件按时间间隔检测缺口，阈值为 `max(2 秒, 5×标称采样间隔)`；标称间隔来自有效元信息，缺失时用最多前 1000 个正时间差的中位数，仍不可确定则用 1 秒。导出官方格式会丢失本地分段及扩展字段，操作前明确提示并推荐另存完整本地记录。

## 区间统计与自动停止

统计包括样本数、时间跨度、有效覆盖时长、各曲线最小/最大/时间加权平均、电量 Ah/mAh、能量 Wh/mWh，以及区间有效时长、电量、能量占全记录的百分比。零分母显示不可计算。

采用实际时间的梯形积分；只积分同段内有效相邻样本。间隔超过 `max(2 秒, 5×所选采样间隔)` 时断段；“全部接收”使用滚动正间隔中位数作为标称间隔。暂停、断连、重启、睡眠段不插值积分。选区边界落在有效相邻点之间时线性插值；落在缺口时不跨缺口补值。平均按有效覆盖时长加权；只有一个点时显示该点读数、积分为零。

有符号量、正向量、反向量和绝对累计量分开统计；跨零电流/功率的线性区段拆分后积分，不能取端点绝对值造成多算。设备自带 Ah/Wh 和电脑积分明确标注来源，互不替代。

可选自动停止：电流绝对值或非负功率低于用户阈值连续达到指定秒数后停止保存记录，保留预览；默认关闭。条件用实际收到的有效遥测判断，不用抽稀曲线判断；暂停、缺口或断连重置计时，不计入触发持续时间。输入必须有限且非负，持续时间必须大于零。

## 验证和交付

先验证只读采集：需要实际正常模式 K2 才能声称协议实测通过。核对正负电流、设备读数、有效频率和遥测校验行为；无需擦写授权。当前设备未连接，不能把模拟数据当作硬件完成证明。

自动验证覆盖解析边界、非有限数值、方向保留、抽样时间、跨天 CSV、官方可选列、SQLite 本地与官方合成格式往返、异常时间、取消导入、断连/暂停分段、跨零积分与边界选区、磁盘/后台错误、退出提交、自动停止及设备互斥。使用独立计算的已知波形和故障注入验证，避免只检查实现生成的数据。官方真实导出文件与 Windows 回读有样本/环境后补测，交付时注明静态兼容与实测的区别。

加速生成至少百万样本验证分页、记录数量和有界内存；做 100 样本/秒持续采集与退出保存验证。加速负载只能证明存储规模，不等同一天连续实测。运行现有 Python/Swift 回归，核对真实窗口操作和双架构打包；Intel 未在实际机器运行时明确说明。

按顺序提交并推送：协议与许可证、记录与文件交换、统计与查询、原生页面与设备互斥、打包与文档。最终交付实际可用页面及 Universal2 应用，不加入模拟/测试入口。
