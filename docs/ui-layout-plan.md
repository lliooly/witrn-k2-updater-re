# UI 布局实现计划

依据：[设计规格](ui-layout-design.md)。用户已确认设计，并允许跳过缺失的 writing-plans 技能。

1. 在窗口层统一右侧连接栏、连接摘要和固定任务状态区；保留共享 Store 生命周期，新增的展示状态不调用设备接口。
2. 调整导航顺序与分组，默认打开上位机；统一工程工具栏及维护菜单，保留原快捷键与确认弹窗。
3. 上位机优先显示读数、记录控制与曲线；记录设置和统计折叠，历史记录独立展示，保留所有文件格式和导出选区功能。
4. 整理固件升级步骤、自定义编辑区与 E-Mark 的操作归属；设备读写与本地保存分别展示。
5. 构建并运行现有 Swift 和 Python 回归；对连接摘要的等待／断开／DFU 展示补充针对性验证。
6. 运行应用检查五个页面、连接栏展开／收起、最小窗口尺寸、菜单入口和离线编辑操作；不执行真实设备擦写。

所有变更在当前分支完成；不创建 worktree。Python 后端、K2Core 文件格式与设备协议保持原样。
